# Code of Conduct

## Our Pledge

We want ARPoseStreamer to be a welcoming, practical, and respectful project for researchers, students, developers, and hobbyists.

Contributors and maintainers are expected to help create an environment that is:

- respectful
- constructive
- technically honest
- friendly to newcomers

## Expected Behavior

Examples of positive behavior include:

- asking questions in good faith
- giving actionable technical feedback
- being respectful in disagreement
- focusing discussion on the code, documentation, and experiments
- helping others reproduce issues and fixes

## Unacceptable Behavior

Examples of unacceptable behavior include:

- harassment or personal attacks
- insulting or dismissive language
- intentionally misleading technical claims
- publishing private information without permission
- behavior that makes participation feel unsafe or hostile

## Scope

This code of conduct applies to:

- GitHub issues
- pull requests
- discussions related to this repository

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, pull requests, or other contributions that violate this code of conduct.

## Reporting

If you experience or observe unacceptable behavior, please open a private communication channel with the maintainer if possible, or open an issue if appropriate and safe.

## Attribution

This document is a short, simplified project-specific code of conduct inspired by common open source community standards.
