# ARPoseStreamer 中文导览

语言 / Language: [English README](../README.md) | [简体中文](README.zh-CN.md)

ARPoseStreamer 是一个轻量的 iPhone ARKit 位姿采集与主机接收项目，支持：

- iPhone 端 ARKit 6-DoF 位姿流
- macOS / Windows 主机接收与可视化
- 离线 CSV 标定与验证
- 机器人末端与 ARKit 相机的 hand-eye 标定
