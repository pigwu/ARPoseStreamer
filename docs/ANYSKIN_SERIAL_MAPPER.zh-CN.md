# COM 磁传感器对应关系工具

`anyskin_serial_mapper.py` 用来直接查看串口磁数据，并判断 5 个物理磁传感器分别对应数据中的哪个通道。默认端口为 `COM9`、波特率为 `115200`。

## 启动

```powershell
pip install -r requirements_visualizer.txt
.\run_anyskin_serial_mapper_windows.ps1
```

也可以指定端口和波特率：

```powershell
.\run_anyskin_serial_mapper_windows.ps1 -Port COM9 -Baud 115200
```

## 判断对应关系

1. 连接串口，让磁铁远离全部传感器。
2. 等待自动建立基线，或点击“设置无磁铁基线”。
3. 在界面选择物理位置 `P0`，把磁铁靠近该位置的传感器。
4. 观察响应柱状图；稳定后点击“记录当前对应”。
5. 对 `P1` 到 `P4` 重复操作。

工具使用三轴磁场向量相对基线的变化量，而不是只比较单一轴。置信度表示最强通道相对第二强通道的区分程度，建议记录时至少达到 40%。如果多个通道同时明显变化，应把磁铁贴近目标位置、远离相邻位置后重试。

## 支持的数据格式

- 每行 20 个数：`S0..S4`，每个传感器为 `T,X,Y,Z`
- 每行 15 个数：`S0..S4`，每个传感器为 `X,Y,Z`
- 每行一个芯片：`chip 1 addr=0x0E status=0x00 t=24.98 x=... y=... z=...`；工具会自动凑齐 5 个 chip
- 上述数据前带序号、时间戳的文本行
- JSON 数组、`values`/`sensors` 数组，或包含 `S0` 到 `S4` 的对象
- 96 字节 ASKN v1 二进制包：`<IIQ20f`

文本分隔符可以是逗号、分号、空格、制表符或竖线。“自动”模式会同时识别文本和 ASKN 二进制数据。勾选“保存 CSV”后，数据写入项目下的 `logs` 文件夹。
